# Memory

Минималистичное Android-приложение для тренировки памяти в стиле «Reaction» от nix games:
кремовый фон, тёмные рамки, крупный жирный шрифт, ничего лишнего.

Нативное приложение на **Kotlin + Jetpack Compose** — без WebView и веб-движков.

## Упражнения

| № | Название | Что тренирует | Результат |
|---|----------|---------------|-----------|
| 1 | Вспышки | Повторить порядок вспышек клеток (тест Корси) | длина последовательности |
| 2 | Матрица | Запомнить закрашенные клетки | число клеток |
| 3 | Число | Запомнить и ввести число | число цифр |
| 4 | Задом наперёд | Ввести цифры в обратном порядке | число цифр |
| 5 | Пары | Найти все пары карточек | число ходов (меньше — лучше) |
| 6 | Скрытые числа | Нажимать спрятанные числа по возрастанию | количество чисел |
| 7 | Цвета | Повторить последовательность цветов | длина последовательности |
| 8 | Было или нет | Встречалось ли слово раньше | правильные ответы |
| 9 | Что изменилось | Найти фигуру, сменившую цвет или форму | число фигур |
| 10 | Где это было | Вспомнить расположение фигур | число фигур |
| 11 | Список слов | Найти запомненные слова среди других | угадано из 24 |
| 12 | Пары слов | Вспомнить, какие слова шли вместе | угадано из 15 |
| 13 | Совпадение | Совпадает ли фигура с предыдущей (45 с) | очки |
| 14 | Два назад | 2-back: совпадает ли буква с той, что была два шага назад | точность, % |
| 15 | Пропажа | Какой фигуры не хватает | число фигур |
| 16 | Очерёдность | Восстановить порядок появления фигур | число фигур |

В «уровневых» упражнениях задание усложняется после каждого верного ответа, ошибка отнимает
одну из трёх жизней. Результаты сохраняются; у каждого упражнения есть история с лучшим и средним
результатом и графиком последних игр.

Настройки: звук, вибрация, тема (системная / светлая / тёмная), скорость показа заданий,
сброс результатов.

## Сборка

Нужны JDK 17+ и Android SDK (платформа 36).

```bash
./gradlew testDebugUnitTest   # юнит- и Robolectric-тесты
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

GitHub Actions собирает APK при каждом пуше в `test` и `main` — его можно скачать во вкладке
**Actions → Android → Artifacts**.

APK подписан общим ключом из `keystore/` (пароль в `app/build.gradle.kts`), чтобы сборки из CI и
локальные ставились поверх друг друга. Для публикации в магазине нужен собственный приватный ключ.

## Устройство кода

```
app/src/main/java/com/horvickk/memory/
├── MainActivity.kt          навигация между экранами
├── audio/                   синтез коротких звуков и вибрация
├── data/                    настройки и история результатов (SharedPreferences)
├── game/
│   ├── Game.kt              модель упражнения и контекст игры
│   ├── LevelGame.kt         общая схема «уровни + 3 жизни»
│   └── exercises/           сами упражнения и их каталог
└── ui/                      тема, компоненты, экраны
```

Новое упражнение — это `@Composable`-функция, получающая `GameContext`, и запись в
`game/exercises/Catalog.kt`.
